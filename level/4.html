Operating Systems — للمبرمجين

فهم نظام التشغيل بسهولة

الـOS هو المدير الرئيسي للكمبيوتر: ينظم البرامج، الذاكرة، المعالج، الملفات، المستخدمين، الأجهزة والخدمات، ويحدد من يستطيع الوصول إلى ماذا.

OSمدير الجهاز
Processبرنامج يعمل
Permissionما المسموح به
Driverحلقة وصل مع الهاردوير
1

كيف يعمل الـ OS؟

الـOperating System هو البرنامج الأساسي الذي يعمل كوسيط بين التطبيقات والهاردوير. التطبيق لا يتعامل عادةً مع مكونات الجهاز مباشرة؛ بل يطلب من نظام التشغيل، والنظام ينسق الوصول إلى الموارد.

أنت / المستخدم
↓
Application — مثل Chrome أو Python
↓
Operating System / Kernel
↓
Drivers
↓
Hardware — CPU / RAM / SSD / Network
الفكرة الأساسية: الـOS يمنع البرامج من امتلاك حرية مطلقة، وينظم استخدام CPU وRAM والملفات والأجهزة.
2

Users — المستخدمون

نظام التشغيل يحتاج أن يعرف من يستخدم الجهاز لأن كل مستخدم قد يملك ملفات وإعدادات وصلاحيات مختلفة.

Ahmed
حساب شخصي وملفات خاصة.
Administrator
صلاحيات عالية لإدارة النظام.
Guest
صلاحيات محدودة.
Groups
يمكن وضع عدة مستخدمين في مجموعة ومنح المجموعة صلاحيات.
3

Permissions — الصلاحيات

الـPermission تجيب عن سؤال بسيط: هل هذا المستخدم أو البرنامج مسموح له بهذا الفعل؟

User / Process
↓
طلب الوصول إلى ملف
↓
Permission Check
↓
✅ مسموح    أو    ❌ Permission Denied

في Linux

rwx rwx rwx

Owner   → rwx
Group   → r-x
Others  → r--

r = Read    w = Write    x = Execute 

chmod 755 script.sh
4

Processes — العمليات

الـProcess هو برنامج أثناء تشغيله. الملف الموجود على القرص هو البرنامج، لكن عندما تشغله ينشئ النظام Process ويمنحه موارد مثل الذاكرة ووقت المعالج.

احفظها: Program = الكود الموجود على القرص، Process = الكود أثناء التنفيذ. 
Chrome.exe على القرص
        ↓
تشغيل
        ↓
Chrome Process
        ↓
Memory + CPU + Threads + Resources
5

Services — الخدمات

الـService هو برنامج أو وظيفة تعمل غالبًا في الخلفية وتتم إدارتها بواسطة نظام الخدمات. مثال: Web Server، Windows Update، Networking، Antivirus.

Computer Starts
↓
Service Manager
↓
Service
↓
Process يعمل في الخلفية

مثال Linux مع systemd

systemctl start nginx
systemctl stop nginx
systemctl status nginx
مهم: Service وProcess ليسا نفس الشيء. الـService هو مفهوم لإدارة خدمة تعمل في الخلفية، وقد يؤدي تشغيل الخدمة إلى تشغيل Process أو أكثر.
6

Environment Variables — متغيرات البيئة

هي قيم وإعدادات توفرها البيئة للبرنامج، غالبًا بالشكل: NAME=VALUE. 

PORT=3000
NODE_ENV=production
API_KEY=xxxxx
PATH=...

مثال في JavaScript

const port = process.env.PORT;

بدل أن تثبت قيمة 3000 داخل الكود، تستطيع تغييرها حسب البيئة: 

Development → PORT=3000
Production  → PORT=8080
أشهر Variable: PATH — يحدد مسارات يمكن للنظام البحث فيها عن البرامج التنفيذية.
7

Drivers — التعريفات

الـDriver هو طبقة برمجية تساعد نظام التشغيل على التواصل مع جهاز أو مكون معين.

Application / Game
↓
Operating System
↓
Driver
↓
Hardware — GPU / Wi-Fi / Audio / Printer

أمثلة:

GPU Driver
Audio Driver
Wi-Fi Driver
Bluetooth Driver
Printer Driver
Storage / USB Driver
8

Logs — السجلات

الـLogs هي سجل للأحداث التي تحدث في النظام أو البرامج. عندما تحصل مشكلة، تساعدك السجلات على معرفة ماذا حدث ومتى وأين. 

10:00 Server started
10:01 User logged in
10:03 Database connection failed
10:04 Service restarted

Linux

journalctl
journalctl -u nginx

Windows

توجد منظومة Windows Event Log ويمكن عرض الأحداث عبر Event Viewer.

بدل أن تقول: "السيرفر لا يعمل"، افتح الـLogs وابحث عن السبب الحقيقي. مثال: Port already in use.
